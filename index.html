Langkah-Langkah Pembaikan:

  • Buka Google Sheet: Pastikan fail di Google Sheet telah diterbitkan ke Web melalui menu File > Share > Publish to web dan pilih format Comma-separated values (.csv).
  • Akses Awam: Pastikan tetapan capaian General Access Google Sheet adalah "Anyone with the link" (Viewer) dan bukannya disekat untuk staf/organisasi tertentu sahaja.
  • Isu Protokol Fail Komputer (file:///): Jika membuka fail HTML ini secara terus dari komputer tanpa pelayan web (contohnya Live Server), pelayar anda mungkin menyekat capaian CORS. Gunakan butang "Muat Naik CSV Manual" di bawah.
